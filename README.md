## 🚀 Featured Project

### 🦖 [Clipzilla](https://github.com/UmarIqbal000/Clipzilla)

**Monster that devours long-form and spits out shorts.**

An open-source, local-first tool that turns long YouTube videos into viral vertical shorts using a **6-stage AI pipeline**: download, transcribe, AI clip analysis, face-tracked reframing, animated captions, export. Ships with a full **React + Vite Web UI** and a **Click CLI**, and can auto-publish to YouTube, Instagram, and Facebook.

🧠 AI clip discovery via interchangeable LLM providers (Ollama Local/Cloud, or any OpenAI-compatible API)
🎯 Speaker face-tracking reframe (MediaPipe + EMA smoothing) for 9:16 vertical crops
💬 Animated karaoke / single-word caption presets
⚙️ Runs on 8 GB RAM, no GPU required, using `faster-whisper` int8 on CPU
🐳 One-command Docker deploy with FastAPI backend and SQLite job queue
